## Introduction to Operating Systems

Tags: #OperatingSystem 

**Operating System**: 
- a program that acts as an intermediary between a user of a computer and the computer hardware.
- the set of programs that controls a computer.
- an important part of almost every computer system.
- examples of operating systems: UNIX, Mach, MS-DOS, MS-Windows, Windows/NT, OS/2, and MacOs.

**Purpose of an Operating System**: provide an environment in which a user can execute programs. 

**Primary Goal of an Operating Systems**: to make the computer system convenient to use.

**Secondary Goal of an Operating Systems**: use the computer hardware in an efficient manner.

**Computer System**: 
* can be divided roughly into four components: hardware, operating system, application programs, and the users.

![[Pasted image 20250910120831.png]]

**Computer System Components:**
1. ***Hardware***: provides basic computing resources (CPU, memory, I/O devices).
2. ***Operating System***: Controls and coordinates the use of hardware among application programs.
3. ***Application Programs***: Solve computing problems of users (compilers, database systems, video games, business programs(banking software)).
4. ***User***: People, machines, other computers.

**Objectives of Operating Systems**
* To hide details of hardware by creating abstraction.
* To allocate resources to processes (Manage resources).
* Provide a pleasant and effective user interface.
